# Сетки по борьбе (Flutter)

Мобильное приложение для формирования турнирных сеток по борьбе.

## Что умеет
- Турниры (название, дата, место). Возраст считается по году: `год турнира − год рождения`.
- Участники: ФИО, команда (с автоподсказкой), год рождения, вес, пол. Быстрый ввод «Сохранить и добавить ещё» — удобно на взвешивании.
- Автоматическое распределение по категориям из положения:

| Возраст | Веса |
|---|---|
| 6–7 лет | 26 |
| 8–9 лет | 27, 31, 36 |
| 10–11 лет | 36, 40 |
| 12–13 лет | 45, 50, 55 |
| 14–15 лет | 50, 55, 60 |
| 16–17 лет | 55, 60, 65, 70 |
| 18+ | 60, 65, 70, 75, 75+ |

  Тяжелее последнего веса группы — категория «N+ кг». Девушки идут в общую сетку по факту взвешивания.
- Если в весе один участник — он автоматически переводится в категорию выше (если выше никого — в ближайшую ниже), в списке появляется пометка.
- Жеребьёвка: олимпийская сетка 2/4/8/16/32/64, свободные места распределяются равномерно.
  Одноклубники **не встречаются в первой схватке** (кроме веса из 3 человек), дополнительно разводятся по разным половинам сетки.
  Если развести невозможно (одной команды больше половины) — такие пары подсвечиваются красным.
- Редактирование: нажать участника → нажать другое место — меняются местами (можно и на свободное место). Кнопка «Пережеребить».
- Если состав категории поменялся — приложение предупредит и предложит пересоздать сетку. «Сформировать» в списке сеток не трогает ручные правки.
- PDF: одна категория или все сетки турнира (страница A4 на категорию, с подписями судей) — предпросмотр, «Поделиться» (сохранить в файлы, Telegram), печать.
- Данные хранятся на телефоне (offline).

## Сборка

```bash
cd wrestling_brackets
```

```bash
flutter create --project-name wrestling_brackets --org kz.temirpride --platforms android,ios .
```

```bash
flutter pub get
```

```bash
flutter test
```

```bash
flutter run
```

```bash
flutter build apk --release
```

APK: `build/app/outputs/flutter-apk/app-release.apk`

## Структура
```
lib/
  main.dart              — запуск, тема, русская локаль
  models.dart            — Турнир, Участник
  categories.dart        — возрастные/весовые категории, переводы одиночек
  draw.dart              — жеребьёвка и проверка одноклубников
  layout.dart            — геометрия сетки (общая для экрана и PDF)
  pdf_export.dart        — генерация PDF и экран предпросмотра
  state.dart             — хранение (shared_preferences)
  screens/
    home_screen.dart         — список турниров
    tournament_screen.dart   — участники и список сеток
    participant_form.dart    — добавление/редактирование участника
    bracket_screen.dart      — сетка, обмен местами, жеребьёвка
    bracket_view.dart        — отрисовка сетки
assets/fonts/            — DejaVu Sans (кириллица в PDF)
```

Категории правятся в `lib/categories.dart` → `ageGroups`.
